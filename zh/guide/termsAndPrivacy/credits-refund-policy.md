本点数与退款政策适用于由 **HK Word Origin New Wisdom Technology Limited** 运营的 TokensMind 服务。

## 1. 点数性质

TokensMind 点数、额度或预付余额均为虚拟服务点数，仅可在 TokensMind 平台内使用。

点数：

- 仅可用于调用 AI API 或购买符合条件的 TokensMind 平台服务。
- 不是现金、银行存款、电子货币、储值支付工具、证券或投资产品。
- 不产生利息。
- 不可提现。
- 除非我们以书面形式明确允许，否则不可转让给其他用户。
- 不可兑换现金。
- 不可用于购买 TokensMind 平台以外的商品或服务。
- 不可用于违法、滥用或违反政策的活动。

## 2. 退款窗口期

付款成功后 **1 个自然日** 内，你可以申请退还未使用的已购点数。

退款请求必须通过仪表盘中显示的支持或退款渠道提交，并必须包含：

- 账户邮箱。
- 订单 ID。
- 支付金额和币种。
- 支付时间。
- 退款原因。

我们可能会要求你提供其他信息，以核验身份、防止欺诈，并遵守支付网络规则。

## 3. 不可退款项目

以下项目通常不可退款：

- 已用于 API 调用或平台服务的点数。
- 促销、奖励、免费、试用、测试、优惠券或人工赠送的点数。
- 与因欺诈、滥用、违法活动、规避制裁、支付滥用、拒付滥用、账户转售、API key 转售或严重违反政策而被暂停的账户相关的点数。
- 因用户侧集成错误、API key 泄露、模型选择错误、意外高用量，或因未妥善保护凭据而导致的未授权访问所产生的费用、损失或成本。

## 4. 重复付款

如果同一订单被扣款超过一次，我们会核验支付记录，并采取以下任一措施：

- 将重复扣款退回原支付方式；或
- 如果你提出请求且我们批准，将重复扣款金额充值到你的 TokensMind 账户。

## 5. 支付成功但点数未到账

如果支付成功但点数未到账，请携带订单 ID 和支付凭证联系支持团队。核验后，我们将：

- 补发缺失的点数；或
- 如果无法发放点数，则退还该笔付款。

## 6. API 调用失败但点数已扣除

如果 API 调用因平台侧或提供商侧错误而失败，且点数被错误扣除，我们可能会在审核日志后恢复点数或进行退款/调整。

因以下原因导致的失败，不保证退款或恢复点数：

- 请求格式无效。
- 模型名称无效或不受支持。
- 用户侧超时设置。
- 客户端网络中断。
- 用户侧重试逻辑。
- 用户应用程序缺陷。
- API key 泄露或被滥用。
- 请求因违反政策而被阻止。

## 7. 模型不可用

模型可能因供应商故障、容量限制、政策限制、维护、法律要求或商业变更而不可用。

如果在成功完成可计费请求之前模型不可用，则不应对该失败请求收取用量费用。如果发生平台侧计费错误，我们会在核验后恢复点数或进行调整。

模型临时不可用并不会自动使用户有权退还账户中所有未使用点数，除非相关未使用点数仍处于 1 个自然日退款窗口期内，或适用法律要求退款。

## 8. 账户暂停或终止

如果你的账户因严重违反条款、欺诈、滥用、违法活动、支付风险、拒付滥用、规避制裁、账户转售、API key 转售或违反上游供应商政策而被暂停或终止，在法律和支付网络规则允许的范围内，未使用点数可能被冻结、没收或暂不退还。

如果你的账户因与不当行为无关的原因被关闭，且请求仍处于 1 个自然日退款窗口期内，或适用法律要求退款，你可以申请退还未使用的已购点数。

## 9. 退款方式和时间

经批准的退款通常会退回原支付方式。处理时间取决于支付处理机构、发卡机构、银行和支付网络。

在法律和支付网络规则允许的范围内，我们可能会从退款中扣除已使用点数、拒付费用、支付处理机构费用、货币兑换差额或税费。

## 10. 拒付

请在发起拒付前联系支持团队，以便我们调查并解决问题。我们会保留订单、用量、点数发放、登录、设备、IP、API key、支持和退款记录，作为处理拒付的证据。

存在未解决拒付、疑似未授权付款或支付滥用的账户可能会被暂停或限制。
