本 AI 安全与滥用政策适用于由 **HK Word Origin New Wisdom Technology Limited** 运营的所有 TokensMind 服务。

## 1. 目的

TokensMind 提供 AI 模型 API 访问和相关路由服务。用户不得使用 TokensMind 创建、促成、自动化、扩大、隐藏或分发有害、违法、欺骗性、滥用性或侵犯权利的活动。

## 2. 禁止活动

你不得将服务用于：

- 欺诈、诈骗、网络钓鱼、冒充身份、虚假客户支持、凭据盗取、支付欺诈或社会工程。
- 恶意软件、勒索软件、间谍软件、漏洞利用代码、撞库、未授权访问、僵尸网络活动、漏洞利用或规避安全控制。
- 垃圾信息、批量未经请求的信息、虚假评论、互动操纵、账户养号、平台操纵或自动化骚扰。
- 儿童性虐待材料、对未成年人的性剥削、诱骗未成年人，或将未成年人性化的内容。
- 未经同意的性内容、未经同意的私密影像、滥用性 deepfake 或性勒索。
- 在违法或违反供应商政策的情况下提供成人性服务或露骨性内容。
- 未经同意的生物识别、面部识别、语音克隆、冒充身份，或滥用他人肖像。
- 侵犯版权、侵犯商标、盗版、未经授权生成受保护角色或品牌，或侵犯公开权、隐私权或人格权。
- 恐怖主义、暴力极端主义、招募、宣传、严重暴力指导、武器制造，或规避执法。
- 仇恨、骚扰、威胁、公开他人隐私信息、恐吓，或针对受保护群体的非法歧视。
- 非法赌博、非法毒品、非法武器、规避制裁、洗钱，或未经授权提供受监管服务。
- 在缺少必要人工审核和法律合规的情况下，用于医疗、法律、金融、就业、住房、信贷、保险或其他高影响决策。
- 绕过模型提供商的安全系统、账户限制、地域限制、制裁控制、速率限制或监控系统。
- 违反供应商条款转售 API 访问、共享账户、共用供应商账户，或提供未经授权的下游访问。

## 3. 适用的内容类别

本政策适用于通过服务处理的文本、代码、图片、音频、视频、嵌入、文件、提示词、输出、自动化代理、工作流自动化，以及任何其他内容或活动。

## 4. 安全控制

TokensMind 可能使用以下一项或多项控制措施：

- 账户、邮箱、电话、组织、设备、IP、国家或地区、BIN、银行卡、支付和行为风险检查。
- API key 监控和异常检测。
- 速率限制、并发限制、消费限制、模型限制和速度控制。
- 关键词、模式、端点、模型、token 数量和用量激增检测。
- 上游模型提供商的安全过滤器、审核系统和滥用报告。
- 对支持工单、用户举报、争议材料、元数据和提供商警报进行人工审核。
- 临时冻结、增强验证、订单审核、撤销 API key、暂停账户、终止账户或阻止请求。
- 为欺诈、滥用、拒付、法律、监管或执法目的保留证据。

## 5. 出于安全目的处理提示词和响应

TokensMind 默认不持久化存储提示词或响应内容。滥用调查主要依赖元数据、用量记录、支付记录、API key 记录、IP/设备信息、提供商安全信号、用户举报，以及自愿提交给支持团队的材料。

在法律允许且必要的情况下，我们可能会为严重滥用、欺诈、安全事件、支付争议、法律请求或执行本政策而临时保存或审核有限的相关材料。

## 6. 用户义务

你必须：

- 仅将服务用于合法且符合政策的目的。
- 在你自己的产品和工作流中实施合理的保护措施。
- 如果你通过自己的应用提供访问能力，请监控下游用户。
- 妥善保护 API key，并在 key 泄露后及时轮换。
- 遵守供应商条款、安全政策和速率限制。
- 及时回应 TokensMind 关于疑似滥用的询问。

## 7. 举报滥用

请将疑似滥用、违法内容、被泄露的 API key 或安全事件报告至：

邮箱：leon@tokensmind.ai

举报应包括相关账户 ID、在安全可分享情况下提供的 API key ID、请求 ID、时间戳、截图、URL，以及对问题的简要说明。

## 8. 执行措施

在为保护用户、第三方、供应商、支付合作伙伴、执法利益或服务完整性而有必要时，我们可能会在不事先通知的情况下采取行动。执行措施可能包括警告、阻止请求、速率限制、冻结点数、撤销 API key、暂停账户、终止账户、在允许范围内拒绝退款，以及向主管机关报告。
